# Anwendungen — Kurzbeschreibungen

moin — Kurze Auflistung der in diesem Homelab gehosteten Anwendungen und was sie tun.

- Jellyfin — Medienserver (Video/Audio Streaming)
- Forgejo — Git‑Hosting (Forgejo / Gitea‑ähnlich)
- FileBrowser — Web‑basierter Dateimanager
- Vaultwarden — Passwortmanager (Bitwarden kompatibel)
- Immich — Foto‑Management (self‑hosted)
- Netdata — Echtzeit Performance‑Monitoring
- IT‑Tools — Sammlung kleiner Werkzeuge (z. B. netcat, traceroute Web UI)
- ClamAV — Antiviren‑Service (Scanner)

Jede Anwendung hat ein eigenes Compose/VM‑Setup; suche in Docker/ und Proxmox/ Ordnern für Details.
