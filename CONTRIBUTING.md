# ✨ Contributing

Danke, dass du zum Hoinkkoma Homelab Repo beitragen möchtest! Hier ein kurzer Leitfaden mit Emojis, damit alles schön übersichtlich bleibt.

## 🧭 Ablauf

1. Forke das Repository (falls du extern arbeitest) oder erstelle einen Branch im Repo.
2. Erstelle einen aussagekräftigen Branch: `feature/<kurz-beschreibung>` oder `fix/<kurz-beschreibung>`.
3. Öffne einen Pull Request mit einer klaren Beschreibung.

## 📝 Commit-Nachrichten

- Nutze kurze, erklärende Nachrichten (z. B. `docs: Add Jellyfin config example`).
- Verwende das Format `<scope>: <kurze Beschreibung>` (z. B. `proxmox: add backup notes`).

## ✅ Pull Request Template

- Fasse kurz zusammen, was geändert wurde.
- Verlinke relevante Issues.
- Markiere, ob Breaking Changes vorhanden sind.

## 🧪 Tests / Validierung

- Dokumentationsänderungen: kurz prüfen, ob Links und Codeblöcke korrekt sind.
- Konfigurationsänderungen: wenn möglich, Beschreibungen zur Überprüfung beilegen.

## 📬 Kontakt

Bei Fragen bitte ein Issue erstellen oder direkt im PR nachfragen. Danke! 🎉
